# 来源与编辑规则

## 接入原则

`config/sources.json` 只是候选清单。网站名称／主页不能证明存在 RSS、公开接口或可用采集权限。当前全部关闭，需逐一核实。

优先官方 RSS／公开 API；其次为允许获取的公开页面；无法稳定接入时提供人工粘贴链接方式。不要绕过登录、验证码或付费墙。

单个来源启用前记录：主页、具体接口／页面、接入方法、使用说明、核实时间、时区、可提取字段、更新频率、失败策略和一条真实样例。

官方来源确认日期、展期、地点和预约；专业媒体负责发现、报道和背景。官网本身没有足够字段时保持未知，不凭媒体推测完善票价或休馆日。

## 圈内动态

收录与作品、创作和行业人物有关的公开报道：选角与合作、幕后故事、访谈趣闻、公开争议和当事人主动公开的消息。保留报道出处和消息状态，有回应／更正时关联原记录。

不把匿名传闻改写成确定事实；未证实消息默认不进入今日精选。涉及争议时明确各方说法的出处。私人联系方式、住址和来源不明的私人材料不进入内容库。

默认最多约 10% 的精选位，用户可关闭。可在独立筛选中浏览合格报道，无需强制凑满首页配额。

## 器材排除

排除相机、镜头、灯光等评测、跑分、参数对比、购买指南和新品传闻。器材品牌主办的摄影展、作品征集、创作者访谈可收录相应内容；不附带营销评测。

## 发布内容

保存标题、少量必要摘录／自生成摘要、元数据与原文链接；不默认镜像全文或下载报道图片。演示版可用自制占位图；真实图片使用需核实授权。

## 质量检查

核对日本／其他地区的上映日期；检查新闻发布日期和展期是否混淆；检查重复 URL、活动地点和关键证据链接。来源失败显示最后成功更新时间并记录错误，不把旧资讯伪装成最新消息。
