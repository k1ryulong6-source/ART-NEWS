# 日本展览目录与观展记录

`/#exhibitions` 打开站内展览板块。从「筛选 → 地区」切换日本、日本以外或全球，默认日本。报头的「检索」可按展名、场馆等关键词查找展览，结果遵循所选地区和展览筛选。旧 `/exhibitions/` 及带展览 ID 的链接会进入同一套报头、导航和阅读页。展览目录独立存放。同一场展上了新闻时，新闻报道和展览记录各自保留。

## 怎样接近完整

- Internet Museum 按 47 个都道府县分别翻页，将每个地区公布的总数与实际读到的唯一活动链接对照。目录明确显示零条只说明这个来源没有登记。
- Tokyo Art Beat 全国页达到上限时，遍历其公开地区搜索的 65 个分区及后来观察到的分区。将合并后的唯一链接数与全国目录公布的总数核对，并保存每个分区的核对结果。
- 美術展ナビ沿公开的下一页读取至末页。重复分页、读取失败、部分条目无法解析、访问限制和请求预算都进入报告。已取得的条目和历史库存保留。
- 已验证场馆日历直接补入。补源时优先查「无独立官网日历」或目录长期为空的地区，以 [Art Platform Japan 机构名录](https://artplatform.go.jp/museums) 为一份底册，再扩展当地画廊、艺术节主办方、驻地与独立艺术空间。确认公开日历页、活动类型与页面解析后更新源配置。
- 分类可多选，包含绘画与版画、装置、摄影、雕塑、影像与媒体、设计和工艺、历史及古美术、漫画与艺术节；没有足够信息时保留在「综合／待分类」。从明确的目录标签或展名判断类型。只有能明确区分的独立讲座、工作坊、音乐活动才排除。

去重依赖展名、场馆、地区和展期。同名巡展的不同场馆以及后续不同届次保留为独立活动。合并后保留各来源链接及其原展期，场馆官网优先，冲突明示。如果没有可靠的年份或日子，保留待确认。结束或暂时未能再次抓到的活动不会删除，个人记录依旧指向原 ID。

线上 `/reports/japan-exhibitions.json` 可独立核对逐县页数、公布数、实际读到条数、故障、零条结果和官网日历进度。目录对账只能验证所接来源的公开登记范围，离线公告、未登记的画廊与快闪空间等仍可能漏收。

## 什么先看

「在展推荐」在所选地区和类型内取最多 100 场展，分成重点展、专题与企划、常规展、常设展，标出各档数量。即将开展独立按相同级别排序。回顾展、艺术节、重要周年或规模等来源信号决定级别，同级再看场馆官网、来源印证、临期开闭展和个人想去标签。全量清单可搜索，推荐和全量清单均可分页。

「7 天内闭展」在首屏提供独立入口，想去的在提醒区优先。日本用东京日期，其他地区用当地日期。延期、取消、暂定或缺闭展日的项目会显示已知状态。若同时有两个日期，提示可能更早的闭展日并附官网核对。在「筛选 → 个人标签 → 不感兴趣」查看已隐藏的展览，可在其中撤销标签。原收藏、评分和笔记仍随记录保存。

## 记录和更新

想去、去过、不感兴趣互斥，展览收藏独立。笔记最多 4000 字，评分为 1–5 分。可在正文观展信息中收藏场馆，已收藏场馆的即将开展和过去 14 天内开幕的展览优先出现在「收藏场馆新展」。场馆以核实地点和展览配置的场馆别名生成 ID。观展记录和场馆收藏随浏览器存储键 `culture-desk-exhibition-log-v1` 导入导出，旧备份可继续导入。

展览清单沿用资讯页的文字导航与细分隔线。桌面三列，窄屏两列。海报按原比例铺满栏宽，展名、场馆和展期排在图下方。点海报或展名打开同一个 `/#exhibition/<展览ID>`。正文使用新闻阅读器的标题、正文与原文切换、分享和返回控件。站内正文只请求该场 JSON，标注来源、图源、公开日文介绍或列表短介。来源仅公布时间地点时直接展示资料与出处。覆盖报告的 `public_descriptions` 按公开介绍、短介、待补统计。

日历的「展览开幕与闭展」读取同一目录。标题打开同一篇展览正文，返回时回到所选日期。

`config/exhibitions-jp.json` 管理公开目录、地区表、场馆页和别名。`python scripts/collect_exhibitions.py` 更新 `data/exhibitions-jp.json`。`python scripts/collect_exhibition_details.py` 按近期闭展、重要展与场馆官网优先补 `data/exhibition-details.json`，失败的来源 URL 五天后可再尝试。美術展ナビ的 `/exhibitions/` 提供展讯，`/topics/` 继续提供新闻。独立 GitHub Actions 按东京 06:20 和 18:20 调度，分站限流，跨站并行，发布展览、正文和覆盖报告。便携单文件预览内联展览和已取得的介绍，本地 FastAPI 同样支持独立目录及单场地址。
