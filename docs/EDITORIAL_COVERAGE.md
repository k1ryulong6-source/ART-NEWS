# 地区与媒体分开的采集配置

当前策略：先按电影、艺术、摄影分别设置国家/地区的编辑关注等级，再在关注地区内按媒体权重分配正文抓取名额。来源目录在config/sources.json，领域/地区策略在config/editorial-regions.json；不使用媒体总部推断报道地点或艺术家国籍。

地区等级表示本平台投入采集资源的优先级，不是国家、民族、艺术家或作品价值排名。日本艺术与摄影列一级重点；伊朗电影列重点，但不因此把其所有艺术报道自动抬到一级。所有未单列国家/地区默认三级“全球发现”，始终保留入口。国家或地区发生重大新闻，无论等级都优先。

| 维度 | 配置 | 含义 |
| --- | --- | --- |
| 地区创作关注 | channels的tier_1/tier_2、default_tier | 各领域的来源建设与资源投入方向 |
| 国际媒体价值 | editorial_focus.media_weight.international | 跨地区报道影响/关联价值的编辑初值 |
| 本地专业价值 | local_specialist | 明确关注地区/领域的原创采访与专业报道价值 |
| 发现价值 | discovery | 新作者、较少被报道的创作者、独家项目的发现价值 |
| 出版方所在地 | publisher_country | 只描述媒体出版方，不参与推断单篇报道地或作者国籍 |

三个媒体分数是0—100的可调整编辑初值，不是实测读者占比、客观质量或真实性结论。媒体大小和作者价值没有直接换算关系；不得在界面写成“某国艺术家不行”或把媒体影响分数当作者分数。

单篇报道的涉及地区有明确元数据时，正文名额按该地区关注度处理，即使来自另一国媒体。地点未知时只使用明确的来源关注方向/全球通道；报道涉及地不等于艺术家国籍。

强国际媒体即使不以当地创作为重点，也可进入独立国际渠道；role=global_core或international>=85均可。当地创作需要重点跟进、但缺少可靠本地媒体时，用国际专业媒体与周边地区来源补位，并在priority_country_gaps继续标明缺口。跨地区报道仍可保持country未知，不为了统计好看补造。

所有启用RSS仍每轮读取，当前公开调度约每2小时；分级不用于丢弃RSS条目。读取顺序先轮转地区，再在地区内按媒体权重排序。有限正文抓取预算中，头条和重大消息优先；剩余新正文名额约20%给发现来源、约30%给国际渠道，有候选且紧急稿未占满时执行。地区权重一/二/三级为3/2/1轮，地区内按媒体权重轮转；候选不足时名额回流。旧稿复查份额保留，来源多不等于无限提高单次抓取上限。

全文翻译仍先公共首页主头条和各栏首篇，之后按重要性/时效与旧稿交错；本次不改变500请求/太平洋日免费保护上限，不重新翻译已有有效AI稿，也不增加第二轮校对。

## 证据与接口

- 正式静态版：/reports/regional-coverage.json。本地服务：/api/editorial-regions或同一reports路径。
- 前端已有bootstrap.coverage.editorial_regions，可由Claude决定如何呈现；本次没有改动报纸视觉。
- 报告包含地区×领域来源分配、各媒体独立分数、真实RSS核对成功/失败、来源库存量、未定位文章数、一级关注国家缺少专门来源的清单。
- source_focus是编辑分配，inventory_from_assigned_sources只表示来自这些来源的条数，不表示发生在该地区的文章数。global_completeness保持unknown。
- 新增来源实测证据：data/regional-source-research.json。HTTP 200、RSS解析、抽样公开正文成功分别记录；不把本地成功冒称GitHub也成功。

本轮新增11个RSS：ART iT日本语、ARTnews JAPAN、ArtAsiaPacific、Canvas、Artishock、ZUM、Blind、ArtThrob、TAKE on Art、Africanah、Lenscratch。配置共39启用源，其中30 RSS、9官方页面。首次列表可解析149条是初次补库候选，不是一天新增149条。部分媒体低频更新，保留真实旧日期；多年未更新、跨领域、无有效item或读取失败的其他候选未启用。

复核建议：优先补一级关注国家的专门来源空白、地区间失衡和长期失败；同时抽查国际媒体是否报道关注地区的创作者。不要仅用这批RSS的入库比例证明世界新闻完整，不为了用满额度重复抓取或翻译。
