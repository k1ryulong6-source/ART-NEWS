# 日历的排期和来源

公开站 `/#calendar` 先选地区，再选活动。默认东京和电影。东京视图也收录日本全国院线上映日。流媒体首播汇总所有收录地区。适用地区以出处为准。

- 已有资讯库提供 Diaphana 法国上映、BFI 影展及海外展览。展览目录提供日本展览的图片、开闭展和站内详情，带「不感兴趣」的展览只在个人专区列出。
- 「院线上映」默认显示整月，合并映画.com 的本周和分月公开日。按购票入口或作品页的剧场公开日识别混合排期中的院线条目。尚待确认类型或日期的条目数量列在排期来源。「日本院线在映」核对映画.com 各页与目录标示总数，按作品浏览并查询可用场次。
- 东京逐场排期使用 Eurospace、Theatre Image Forum、新文芸坐和 Cinema Vera Shibuya 的官网，以及映画.com 东京场馆目录的已核实场馆。按东京当地日期和时刻列出，附场馆排片出处和能核实的购票链接。
- 「流媒体首播」须有片方或平台的首次线上发行依据和明确日期。此前仅在影院或电影节放映的电影可以收录。旧片回库、转平台或地区重复上线，以及缺少首播证据的排期与月度片单均不进入日历。「全部活动」执行同一规则。Apple TV Press 的电影目录日期须与首播公告对上，About Netflix 及 Disney+／Hulu 读取单部电影公告。

同一展览关联到统一展览 ID。其余排期以规范化标题、日期、场馆与放映时刻比对。电影在同一天同一影院的同片场次共用一张海报，逐场显示当地时间和购票入口。同一部电影、平台与日期的原名和地区版本共用一条首播记录。月历标记明确的放映、上映、开幕、闭展和流媒体首播日。本月清单按天分组和分页。摄影征集已从日历、检索快捷入口和日历导出移除。

点击活动海报或标题打开站内详情。已有展览正文沿用展览阅读页，其他活动可通过 `#calendar/<id>` 直接打开。读页显示已知日期、地点或平台、海报、场次和必要的购票、观看、出处链接。返回会恢复日历筛选、页码和滚动位置。

影片详情优先展示已保存的中文简介，页内可继续阅读站内介绍。排期须与站内资料的来源链接一致。没有相应中文时，使用作品列表、作品页或平台公开的原文段落并标语种。资料按作品复用，有明确证据时会列出导演、片长和同一作品当前已收录的场次。`/film-calendar.json` 的 `films` 使用 `profile_id` 指向 `profiles`。

### 片名和海报

页面优先显示从公开豆瓣电影结果核实的中文片名，保留排期原题和相应的豆瓣入口。还没有可靠匹配时显示片方列明的原名，或排期原题。院线、影院和平台公开资料提供作品原名、制作年份与剧场海报；已确认同一作品时也能通过 Wikidata 的条目编号交叉核对豆瓣和 TMDB。电影节片单和多片联合场保留节目名。

电影卡优先显示可核实的海报，也采用片方或平台的剧照、联映与片单节目图。主图打不开时依次尝试已保存的备用图。原站的默认电影占位图会被筛除。海报、备用图、图片类型和出处保存在 `/film-calendar.json` 的排期、在映作品或 `films` 元数据中。联映图按节目单独计数。

排期采集之后，自动读入已保存的 `data/film-metadata.json`，按片名、场馆排期出处和适用年份复用核实结果。优先核对当前和即将放映的片，给以往排期留出一部分核对名额。查到资料或重试都记录实际结果，站上保留全部活动 ID。可用 `python scripts/collect_film_calendar.py --metadata-only` 独立补资料。

`config/film-calendar.json` 配置公开排期来源。`python scripts/collect_film_calendar.py` 更新 `data/film-calendar.json`。GitHub Actions 在东京 07:35、17:35 调度，随后发布资料与来源状态。采集失败时保留已核实的记录。`/film-calendar.json` 可核对各来源的最近读取及逐条出处。

另经核实的单片首播可写入同一配置的 `verified_premieres`，记录作品页、正式公告、平台与日期。收录记录的 `premiere_source_url` 供读者在详情中核对。单纯的配信日期继续从旧日历入口过滤，已归档资讯仍可阅读。
