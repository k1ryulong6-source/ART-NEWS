优先官方 RSS／公开 API；其次为允许获取的公开页面；无法稳定接入时提供人工粘贴链接方式。不要绕过登录、验证码或付费墙。

单个来源启用前记录：主页、具体接口／页面、接入方法、使用说明、核实时间、时区、可提取字段、更新频率、失败策略和一条真实样例。

官方来源确认日期、展期、地点和预约；专业媒体负责发现、报道和背景。官网本身没有足够字段时保持未知，不凭媒体推测完善票价或休馆日。

## 圈内动态

收录与作品、创作和行业人物有关的公开报道：选角与合作、幕后故事、访谈趣闻、公开争议和当事人主动公开的消息。保留报道出处和消息状态，有回应／更正时关联原记录。

不把匿名传闻改写成确定事实；未证实消息默认不进入今日精选。涉及争议时明确各方说法的出处。私人联系方式、住址和来源不明的私人材料不进入内容库。

默认最多约 10% 的精选位，用户可关闭。可在独立筛选中浏览合格报道，无需强制凑满首页配额。

## 器材排除

排除相机、镜头、灯光等评测、跑分、参数对比、购买指南和新品传闻。器材品牌主办的摄影展、作品征集、创作者访谈可收录相应内容；不附带营销评测。

## 发布内容

保存标题、少量必要摘录／自生成摘要、元数据与原文链接；不默认镜像全文或下载报道图片。演示版可用自制占位图；真实图片使用需核实授权。

## 质量检查

核对日本／其他地区的上映日期；检查新闻发布日期和展期是否混淆；检查重复 URL、活动地点和关键证据链接。来源失败显示最后成功更新时间并记录错误，不把旧资讯伪装成最新消息。

## 2026-10-13 v0.3 全球接入核实

六个新增 RSS 均实际 HTTP 200 且有有效 item；Tate 页面有独立 Exhibition 卡片、Tate Modern 场馆、明确日期区间。真实采集目前 235 条内容、36 项活动，重复采集全部 inserted=0。公开快照保存原标题、原文链接、原文语言、发布时间和地区证据状态。

Tate 用卡片内部日期，跳过只有 Until 的闭展日期、缺少年份且跨年的区间以及游览／工作坊卡片；同卡片会员票信息不填入普通票价。英国与日本的日历条目独立，不推断其他国家上映日期。MoMA 页面中的杂志推荐日期属于杂志文章，不是展期，故未启用 MoMA 展期适配器。

ArtReview、The Art Newspaper 等候选端点无效，Artpress／Connaissance des Arts 返回受限响应，保留停用，未绕过访问限制。L’Œil 的法语端点样本仍为英文，未重复接入并声称法语覆盖。世界范围仍不是所有地区的完整报道；优先补充非英语及亚洲、非洲、拉美官方来源。

## v0.4 资料补全与核验

新增六个媒体 RSS 与印度、南非两个官方场馆。核实请求、原文样例、失败和未启用原因见 `data/source-research.json`；持续质量盘点见 `data/quality.json` 与 `docs/COVERAGE.md`。来源失败保留此前成功内容，不改写为“没有展览”。

MAP 的 Ongoing／在线展与装置条目不补造开幕日；周二免费只适用于明确标注的周二，不代表每天免费。Zeitz 的“2026–2027 展季公告”不是一个单展；其 Current 徽标仍覆盖一项已于 2026-10-11 闭展的项目，按完整日期标为已结束。

新加坡国家美术馆的公开列表和 JSON-LD 可读，但样例展览实际已于 2026-09-20 结束，没有假称为当前新展。其来源仍列于研究档案，没有自动启用采集。CinéPOP 虽有有效葡语 RSS，但抽样偏向明星八卦、剧集，本轮不增加八卦来源；保留研究记录。

Artforum、IMA、Rapadura 等源均含部分旧资料；发布时间超过 30 天的资料保留在探索和收藏，默认不进入今日。未知发布时间不以抓取时间补齐；只有已确认的近期／进行中活动可以支持没有发布时间的日历情报。未来日期、重复 URL、器材评测、错误日期和断开的活动关联由核验脚本检查。

GitHub 端验证：21 源成功，Asian Movie Pulse HTTP 403；其 8 条缓存保持。不同运行环境的可达性分别记录，未假称为 22 源在 GitHub 全部成功。历史来源状态随公开快照恢复，避免失败时丢失上次成功时间。

## v0.5 剩余资料补齐

BFI 每次采集当前及未来两天、最多三页，并限制在已经核实的 2026-10-07 至 2026-10-18 本届影展日期。只取电影节目分组，排除非电影免费活动；不是声称全影展节目已全部入库。节目数组月数字零起算不用于日期推断，采用完整文字年月日时刻。场次结束时刻未公布就保持空。

Sony 2027 组照截止 2027-01-12 16:00 GMT，单张／青年截止 2027-01-05 16:00 GMT。学生组日期 2026-11-27 明确，简介与规则中出现 13:00／16:00 GMT 冲突，保留冲突，不任选一个。单张组前三张免费，不将额外付费名额说成全免费。活动 GLOBAL 表示全球征集，资格仍按官网规则，不能当作“只能在英国参加”。

法国 Diaphana 的法国本土影院发行与四张首页完整上映卡片已核实；只提取完整年月日，不从影片制作年、网页创建年或月份文案补造年。MMCA 是首尔首页精选四项，非全馆目录。Sony Pictures 片页缺上映年、LensCulture 403、若干候选路径 404 均保留核实记录，未猜测或绕过。
