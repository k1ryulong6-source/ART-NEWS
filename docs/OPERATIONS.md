# 运行与个人数据

## 静态版

运行 `python3 scripts/build_static.py` 后，直接打开 `dist/culture-desk-preview.html`。全部资源内嵌，无远程字体、图片或模型依赖；现代浏览器需要启用 JavaScript。浏览器可能限制 file URL 的持久存储，若提示保存失败，请及时导出，或使用本地服务版。

另可把 `dist/` 放到静态托管服务。当前未完成在线部署；不能以本地文件路径代替已部署网址。

## 服务版

安装 requirements.txt，执行 `python3 -m backend`，访问 `http://127.0.0.1:8000`。配置变量：

| 变量 | 默认 | 用途 |
| --- | --- | --- |
| CULTURE_DESK_DB | runtime/culture-desk.db | 个人数据库路径 |
| CULTURE_DESK_PORT | 8000 | 本地端口 |

浏览器端检测 `/api/health`，成功后使用 SQLite；静态版使用 localStorage。静态模式保存失败时明确提示，不宣称已经持久保存。

数据库在启动时创建并幂等导入虚构示例。外键在每个连接开启。`live` 与 `demo` 查询按 is_demo 分离；当前 live 无记录。日期按活动当地日历值处理，参考“今天”按偏好时区计算；演示参考日固定 2026-10-13。

## 备份／迁移

设置页导出带版本号的 JSON，包含收藏与偏好，不包含凭据。可以导入到另一个静态浏览器或本地服务版；导入前校验格式与内容引用，重复导入不会重复收藏。收藏目标不存在时拒绝并提示，不能凭导出记录造出未备份的资讯。

备份完整真实内容库时，停止服务后复制 SQLite 数据库；不要把实际个人数据放进源码包。静态版只持有示例，本地服务与浏览器状态通过 JSON 迁移，不自动共享。

## 检查与限制

- `python3 scripts/check_project.py`：项目基础一致性。
- `python3 -m unittest discover -s tests -v`：SQLite 与 ASGI HTTP 检查，无需打开端口。
- `node tests/core.test.js`：前端业务逻辑检查。
- `node --check frontend/app.js`：界面脚本语法。

浏览器布局、点击操作、真实下载／上传文件与 TCP 服务监听没有在当前环境完成验收。后台定时器、真实来源采集、模型调用、在线发布均未完成。邮件通知与日历 ICS 导出也未实现。

## 下一次浏览器验收

1. 桌面 1440px 与手机 390px 打开页面，无横向溢出。
2. 搜索、频道／地区／城市筛选组合，关闭圈内动态后消失。
3. 收藏一条资讯与一项活动，刷新后仍在；修改收藏状态后仍保留。
4. 打开日历：日本 10 月 16 日与中国 10 月 23 日分别显示；只到月份的活动不伪造具体日。
5. 导出记录，在另一个浏览器／数据库导入，两次导入数量不增加。
6. 真实模式为空，演示模式每条明确标识；详情的示例链接不会伪装成真实购票入口。
7. 检查键盘导航、详情弹窗关闭与手机菜单。

需要托管时，接力 AI 应先读取 Sites 技能并按其源码同步与发布流程操作。当前没有 Site ID；部署前不要假定已有远程版本。
